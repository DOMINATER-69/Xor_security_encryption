 # XOR Cipher: Data Obfuscation Tool 🛡️

A lightweight and efficient C++ utility designed for string and IP obfuscation using XOR encryption. This tool is ideal for developers and security researchers looking to protect sensitive strings (like C2 IPs or API keys) from static analysis and basic `strings` command detection.

## 🌟 Key Features
- **Two-Way Encryption:** Seamlessly encrypt or decrypt data using the same symmetric key.
- **Hex Encoding:** Outputs encrypted data in a standard hex format (`\x..`) for easy integration into source code.
- **Symbolic Key Support:** Enhances security by allowing non-alphanumeric characters for XOR operations.
- **Cross-Platform:** Works flawlessly on Linux, Android (Termux/Nix-on-Droid), and macOS.

## 🛠️ Installation & Setup

To use this tool locally, follow these steps:

### 1. Prerequisites
Ensure you have a C++ compiler (`g++` or `clang`) installed.
- **Termux:** `pkg install clang`
- **Linux:** `sudo apt install g++`

### 2. Clone the Repository
```bash
git clone https://github.com/DOMINATER-69/Xor_security_encryption.git
```
